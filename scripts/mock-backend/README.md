# Mock backend

Локальная подложка вместо бота Bedolaga — чтобы прокликать кабинет без настоящего бэкенда.

```bash
npm run mock   # mock на :8080 (туда смотрит dev-прокси Vite)
npm run dev    # кабинет на :5173, в другом терминале
```

- Вход: вкладка «Вход», любой email и пароль. Пользователь — админ, поэтому
  переключатель нового дизайна (админка → «Новый дизайн кабинета») работает.
- Данные в памяти (`state.mjs`) и сбрасываются при перезапуске. Покупка тарифа
  списывает с баланса и продлевает подписку. Промокод `POSTQ` — успешный, любой
  другой — ошибка.
- Пополнение работает как с настоящей платёжкой: `POST /cabinet/balance/topup`
  создаёт счёт и возвращает `payment_url` (`/api/mock-pay/<id>`), кабинет
  показывает ссылку. На странице тестовой платёжки «Оплатить» зачисляет деньги,
  «Отменить платёж» отменяет; обе возвращают на `/balance/top-up/result`, где
  кабинет опрашивает статус через `pending-payments`.
- На запросы без обработчика mock отвечает 404 и пишет в консоль `MISS …` —
  так видно, что ещё не замокано. Обработчики: `routes.mjs`, `routes-shop.mjs`.
- `MOCK_SCENARIO=trial npm run mock` — новый пользователь: подписки нет, на
  балансе 100 ₽, доступен бесплатный пробный период (1 день, 10 ГБ). По умолчанию
  (`active`) — активная подписка.
- `MOCK_DELAY_MS` — задержка ответов (по умолчанию 150 мс), `MOCK_PORT` — порт,
  `MOCK_VERBOSE=1` — логировать каждый запрос.
- Экран «Сервис недоступен»: просто остановите mock — кабинет покажет его и сам
  восстановится, когда mock снова запустится.

Админка замокана частично: разделы открываются, но многие списки будут пустыми.
